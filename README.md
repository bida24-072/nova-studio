# Nova Studio - Architecture & Design Website

A premium, multi-page website for a high-end architecture firm. 

## 🚀 Features
- **Interactive 3D Scene**: A floating wireframe Torus Knot built with Three.js.
- **Warm Cursor Highlight**: A golden radial gradient that follows the mouse.
- **Mega-Menu Navigation**: Custom dropdowns for Services and Projects.
- **Sleek Typography**: Playfair Display (Serif) paired with Inter (Sans-serif).
- **Fully Responsive**: Adapts beautifully to all screen sizes.

## 💻 How to Run
Simply open `index.html` in your browser. No build tools required.
